Mario Kart Wii - Mario Kart 8-Esque Controller Bindings by Crissley10

⚠️ I have only tested this with Switch Pro Controllers and Xbox 360 Controllers.

⚠️ MAKE SURE THAT WHILE YOU'RE IN MENUS, YOU
AVOID PRESSING R OR ZR/RT/R2 BUTTONS AS THEY'RE
ASSIGNED TO THE NEUTRAL JUMP/TRICK. USE THE L
BUTTON INSTEAD TO CYCLE THROUGH COSTUMES.

You can download Wheel Wizard (Wiicompiled w/ Retro Rewind [here](https://github.com/TeamWheelWizard/WheelWizard/releases)

FOR USE WITH Dolphin:

1. Select & Cut your 'mario kart wii.ini' file from the 'GCPad' folder (GameCube Controller bindings) or 'Wiimote' folder (Pro/Classic Controller bindings). You can do both if you want.

2. Navigate to your Dolphin 'User Folder'. Usually located on your C: drive separate from Dolphin's executable's folder (tends to usually be either %userprofile%/Documents/Dolphin Emulator/ or on newer versions, %appdata%/Dolphin Emulator/). It can also be accessed through Dolphin itself in the 'File' tab, click 'Open User Folder'.

3. Open the 'Config' folder, then open the 'Profiles' folder, and then...

	a (GCPad). Open the 'GCPad' folder and paste the 'mario kart wii.ini' into that folder. You can now select and load these bindings in the Configuration menu of Dolphin's 'Controllers' settings and enjoy gaming!

	b (Wiimote). Open the 'Wiimote' folder and paste the 'mario kart wii.ini' into that folder. You can now select and load these bindings in the Configuration menu of Dolphin's 'Controllers' settings and enjoy gaming!


FOR USE WITH Wiicompiled w/ Retro Rewind:

1. Make sure you have Retro Rewind installed in Wheel Wizard.

2. (Optional but kind of IMPORTANT) Make a copy of the provided 'GCPadNew.ini' from the 'RetroRewind' folder and keep the copy somewhere secure. HIGHLY RECOMMENDED because it seems that each time Wiicompiled updates, this file gets completely scraped from the files! It's good to have a backup replacement.

3. Select & Cut your 'GCPadNew.ini' file from the 'RetroRewind' folder.

4. Navigate to %appdata%/CT-MKWII/Recomp/Install/RetroRewind/ and paste the file into that folder (replace file if prompted).

5. Open Wheel Wizard and Launch Wiicompiled.

6. Press F10 to open the menu overlay, then open the 'Controller Settings' tab. (IMPORTANT) Make sure your controller is assigned in the 'Assign Connected Controller' section.

7. In the 'Button Mapping' section, clear out all the bindings (set each of them as 'Unassigned'). THIS IS ESSENTIAL as it ensures there are no conflicts with my MK8-esque bindings!

8. By default, the next section, 'Expressions (Dolphin syntax)', should be empty. Simply click on the 'Import from Dolphin' button and you are set! Press F10 to close the menu overlay and enjoy gaming!

	a (OPTIONAL).  You can follow this same step for the 3 remaining player controller ports (Port 2, 3 and 4) in the 'Controller Settings' tab if you plan on doing some local multiplayer!
